# Base del lenguaje genérico de CORE

Estado: fundamento público y agnóstico de dominio.

CORE puede ofrecer un lenguaje común para que una persona, un grupo, un
organismo observado por sensores, un sistema de software o una combinación de
ellos describa una propuesta de acción sin que CORE se convierta en la
autoridad material de esa propuesta.

## Horizonte común

El lenguaje debe apuntar a conservar y mejorar las condiciones de existencia
con el menor daño evitable. No mide el valor de la vida solamente por dinero,
eficiencia o conveniencia, y no convierte una mayoría numérica en permiso para
dañar irreversiblemente a una minoría.

La muerte o el daño a un ser vivo pueden aparecer como una consecuencia de
supervivencia, protección proporcional o alimentación necesaria. Eso no
equivale a justificar la muerte por lujo, exceso, entretenimiento o acumulación
por encima de una necesidad razonable. La distinción debe quedar declarada,
probada y revisable; nunca debe inferirse automáticamente desde una etiqueta.

## Forma mínima

Toda propuesta genérica debería poder expresarse como:

`objetivo -> contexto -> participantes -> necesidad -> alternativas -> regla -> evidencia -> riesgo -> aprobación -> acción -> resultado -> revisión`

Los campos pueden ser ampliados por cada dominio, pero no deberían ocultar:

- qué se intenta proteger o conseguir;
- quién o qué puede resultar afectado, incluyendo seres vivos no humanos;
- si existe una necesidad real o solo una preferencia;
- qué alternativas menos dañinas fueron consideradas;
- si el efecto es reversible y cómo se detiene;
- qué evidencia respalda la decisión y qué incertidumbre permanece;
- quién responde por la autorización y cómo se revisa el resultado.

## Regla de proporcionalidad

Cuando hay conflicto, el lenguaje debe exigir esta secuencia: identificar el
peligro, separar supervivencia de lujo, buscar alternativas, limitar el daño,
aplicar la intervención mínima suficiente y registrar el resultado. Las reglas
que produzcan daño irreversible requieren un umbral de evidencia y revisión
superior al de una acción reversible.

CORE puede validar que esta información exista, que sea coherente y que no se
haya alterado. No puede decidir por sí solo si una vida concreta debe ser
dañada ni reemplazar el juicio responsable, el contexto o las obligaciones
legales aplicables.

## Qué se comparte

Se comparte como aprendizaje congelado la estructura general: definiciones,
criterios de proporcionalidad, métodos de evidencia, límites, esquemas,
pruebas y resultados reproducibles. Se mantienen protegidos los datos
personales, secretos, identidades, ubicaciones sensibles y detalles cuya
publicación aumentaría el riesgo.

Esta separación permite que la humanidad comparta mejores formas de razonar y
coordinarse sin obligar a compartir las circunstancias privadas de quienes
participan.

La composición de contratos que protege estas reglas está documentada en
`CORE_PROTECTIVE_CONTRACTS.md`.
