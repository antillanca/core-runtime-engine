# CORE v11.3.0 Candidate

This document describes the additive, reviewable CORE v11.3.0 candidate. It
is not a published release until the frozen manifest and release review are
approved.

The candidate adds the generic finite ContractProgram registry and aligns the
semantic evaluator with deterministic runtime replay. Registry operations are
closed, bounded and validation-only; malformed operations fail closed.

It also introduces the v11.3.0 frozen-manifest line and preserves all v11.2.1
manifests as immutable historical evidence. DSK v2 private semantics, fixtures
and consumer vocabulary are not part of CORE.

This candidate does not authorize tag, signature, push, deployment, anchoring,
publication or promotion. Those actions require a separate human release
decision.
