# CORE v11.0.1

Hygiene release over the v11.0 clean rebuild. Genericizes example and test
fixtures, tooling literals and documentation references so the public
surface stays domain-agnostic; hardens `scripts/read_bounded_reference.py`
and rewrites `scripts/verify_release.py`.

new installs.
