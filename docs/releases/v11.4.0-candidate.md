# CORE v11.4.0 Candidate

This document describes the additive CORE v11.4.0 candidate. It is not a
published release until the frozen manifest and release review are approved.

## What v11.4.0 adds

ContractProgram v2 — Contract-Oriented Reproducible Evaluation. Traverses 6 eslabones
(PERFIL, VOCABULARIO, QUERYSPEC, RESULTADO, VISTA, EVIDENCIA), validates DSK v3
declarations at each crossing, and emits one of 9 verdicts: pass, incomplete,
scale_violation, authority_violation, loss_undeclared, temporal_violation,
translation_missing, intent_unconfirmed, aborted.

The runtime is deterministic. No LLM is invoked. Same input produces the same
verdict and fingerprint.

## Backward compatibility

ContractProgram v1 (`contract_program.py`) remains unchanged in API and
behaviour. The v1 runtime retains its existing instructions (load, assert,
derive, transition, emit, halt) and its v1 schema. v2 is additive: a new
module (`contract_program_v2.py`), a new schema (`contract_program.v2.json`),
new tests, and new examples.

A minor fix to `contract_program.py` hardens the registry operation: `registry_key`
is coerced to `str` and the exception handler catches `KeyError` and `TypeError`
in addition to `ValueError`. This does not change any passing test or accepted
fixture.

## Migration window

3 releases: v11.4 (this candidate), v11.5, v11.6. Consumers may adopt v2 at
any point during the window. v1 is not removed.

## 9 verdicts

| Verdict | Meaning |
| --- | --- |
| pass | All 6 eslabones have valid DSK declarations |
| incomplete | Missing eslabones or wrong order |
| scale_violation | Missing composition_rule at a crossing |
| authority_violation | Invalid authority_ceiling |
| loss_undeclared | declared_loss missing properties or evidence_refs |
| temporal_violation | temporal_invariant missing captured_at or valid_until |
| translation_missing | translation_map missing source_field or target_field |
| intent_unconfirmed | paraphrase_intent not confirmed by operator |
| aborted | Unexpected finding code |

## Boundary

This candidate does not authorize tag, signature, push, deployment, anchoring,
publication or promotion. Those actions require a separate human release
decision.
