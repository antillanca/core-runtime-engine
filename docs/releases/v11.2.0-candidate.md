# CORE v11.2.0 Candidate

This document describes an additive, reviewable candidate for the next CORE
release line. It is not a frozen or published release.

The candidate adds the deterministic `ContractProgram.v1` runtime surface and
its executable validation contract while retaining the allowlisted, replayable
execution model. The candidate manifest binds the exact repository bytes with
SHA-256 and excludes only its own file from the inventory, as required by the
self-reference policy.

The candidate gate verifies schema closure, exact artifact inventory, file
hashes, canonical fingerprint, contract executability and the existing v11.1
baseline. The v11.1 manifest remains immutable and is not rewritten.

This candidate does not authorize a tag, signature, deployment, network
submission, anchoring, or DSK promotion. Those actions require a separate
human release decision after this candidate review.
