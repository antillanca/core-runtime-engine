# CORE v11.5.0

Status: tagged candidate; formal release blocked.

The immutable Git tag `v11.5.0` exists in the local checkout at commit
`8f83697eaa7aed61ed28e0620362213fb07e78d6`; the local `master` and
`origin/master` tracking ref resolve to that same commit. This proves the
source/tag identity, but does not by itself prove a completed public release.

The formal release gate currently remains blocked because the
`tests-integration` subgroup exceeded its 120-second timeout. Until that gate
passes, this document must not claim that v11.5.0 is formally released,
published as a package, or accompanied by release assets. The historical tag
is not rewritten to change this status.

This release adds the public deterministic Scale Kernel v3 (`core.dsk.v3`).
It validates one typed scale crossing with explicit rational conversion,
composition, declared loss, evidence references and a non-amplifying authority
ceiling. Threshold, resolution and discrete-multiple policies can block an
operation but cannot create authority.

The candidate retains ContractProgram v2 compatibility and includes closed
draft-07 schema validation, deterministic fingerprints, replay evidence and
negative fixtures for schema, data sufficiency, scale, authority and policy
failures. CORE remains a validator and does not call providers or domain
services.
