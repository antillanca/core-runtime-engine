# CORE v12.0.0 — Sealed Public Release

Date: 2026-09-17

Status: sealed public release per HDEV_CORE_V12_SEALED_PUBLIC_RELEASE.md.
All gates G0–G5 executed and verified; G6 closeout pending post-publication.

## Summary

- **Canonicalization**: JCS/RFC 8785 strict canonical JSON (no `default=str`).
- **Fingerprints**: versioned format (`sha256:` for content hashes, `v12:` for envelopes).
- **Envelope**: v12 result envelope with replay matrix (`hdev.core_v12_envelope.v1`).
- **Schemas**: all declare `additionalProperties: false` with JSON Schema draft 2020-12 dialect.
- **Verdict policy**: multi-finding severity order (error > warning > info); `forbidden_authorises_authority` → rejected.
- **Contract registry**: single declarative source at `schemas/core/contract_registry.v12.json`.
- **Schema source**: unified to `schemas/`; `core_runtime/data/schemas/` generated at build time.
- **Derive operations**: explicit `copy` / `count` / `registry` only; unknown ops → `derive_operation_unknown`.
- **v11 immutability**: v11.6.0 frozen as historical baseline; no backports or rewrites.
- **Historical replay**: `legacy_canonical_json_hash` preserves v11 fingerprint compatibility.
