# CORE v11.2.1 Candidate

This document describes an additive, reviewable candidate for the CORE
v11.2.1 patch release. It is not a frozen or published release.

The candidate is a patch on the v11.2.0 line: it fixes
`scripts/verify_release.py` reporting a missing validator script or input
fixture as `passed` instead of `pending_runtime`, and adds a
`checks_summary` telemetry block to the release-verification payload. No
public schema, contract or CLI surface changed. The candidate manifest binds
the exact repository bytes with SHA-256 and excludes only its own file from
the inventory, as required by the self-reference policy.

The candidate gate verifies schema closure, exact artifact inventory, file
hashes, canonical fingerprint, contract executability and the existing v11.1
baseline. The v11.1 manifest remains immutable and is not rewritten.

This candidate does not authorize a tag, signature, deployment, network
submission, anchoring, or DSK promotion. Those actions require a separate
human release decision after this candidate review.
