# CORE v11.3.0

CORE v11.3.0 is the deterministic public release line for the generic
ContractProgram registry and its evaluator/runtime parity.

The release keeps ContractProgram validation-only and non-authorizing, adds
closed registry operations with fail-closed malformed input handling, and
preserves v11.2.1 as immutable historical evidence.

Private DSK v2 semantics and fixtures remain outside CORE. Consumer projects
must use a separately reviewed, version-pinned private adapter.
