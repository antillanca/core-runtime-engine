# CORE v11.0.0

> **Withdrawn.** This release was withdrawn and superseded by
> [v11.0.1](v11.0.1.md). Use v11.0.1 for all new installs.

## Summary

Clean rebuild by whitelist. CORE is repositioned as a deterministic
contract/schema/validator engine only — the CPT simulator legacy (physics
surrogate runtime, DPO datasets, curriculum, world model) and the
self-referential protocol-model certification apparatus (candidate
evaluation, expert router, GAIA pipeline, v8.x-pinned governance freeze)
were archived, not carried forward.

## What's in this release

- 36 public schemas (`schemas/`) plus the `core.*` v1 contract family.
- The validator/derivation scripts used by downstream adapters and external
  workflow tooling, including `read_bounded_reference.py`.
- The generic validator CLI family (agent plan/session/decision-trace,
  anchoring, bounded reference index, chain adapter, downstream bridge
  adapter, human-approved execution gate, parametric template, sensor
  manifest, state watcher, tool invocation).
- The sensor adapter contract and its examples (audio envelope, image
  brightness motion, minimal sensor adapter, wifi CSI, business/privacy
  scenarios) with `check_adapter_compliance.py`, `certify_sensor_fixture.py`
  and `create_adapter_skeleton.py`.
- `core_runtime/cli/*` tooling: validate, lint, doctor, inventory,
  contract_preflight, release_check, bump_version, create_domain,
  sync_template, repair_artifact_paths.

## What moved out

Everything else from the pre-v11 repository, including the CPT simulator
runtime and the protocol-model/expert-router/development-audit/GAIA
ecosystem, is preserved at the `legacy-final` git tag and in
`_archive/core-runtime-engine-legacy/` in the workspace. See
[../CORE_REBUILD_FROM_ZERO.md](../CORE_REBUILD_FROM_ZERO.md) for the full
rationale.

## Compatibility

The carried-forward validator scripts keep their subprocess JSON contracts
stable relative to the pre-rebuild repository, verified by parity smoke tests.
Bounded reference reads work unchanged through `read_bounded_reference.py`.
